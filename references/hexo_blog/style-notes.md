# hexo_blog Style Notes

参考仓库：https://github.com/shanyangcao/hexo_blog

本地目录：`references/hexo_blog`

## 核心风格

- 基于 Hexo Butterfly 主题。
- 整体气质是二次元个人博客，而不是企业 Dashboard。
- 第一视觉来自大幅背景图、透明卡片、圆角、亮青色主题色和活泼图标。
- 内容结构偏“博客首页”：顶部沉浸背景，下面是文章卡片和侧栏小组件。

## 可借鉴元素

- 全屏背景图作为情绪基底，而不是纯 CSS 渐变。
- 内容卡片使用半透明背景、backdrop-filter 和圆角。
- 导航栏使用浅色渐变和高透明度。
- 首页文章卡片可以做成封面图 + 标题 + 摘要，而不是列表。
- 卡片 hover 有轻微放大和颜色反馈。
- 主题色统一为高饱和蓝青色：`#00d1ff`、`#00ffa3`、`#18ffff`。
- 保留一些“个人站”的趣味细节：按钮、悬浮工具、动效、角标。

## 不适合直接照搬的元素

- 动效和装饰很多，直接用于知识 Dashboard 会显得乱。
- 图标、菜单和社交入口太个人博客化。
- 大量外部插件、评论系统、打赏、鼠标特效不适合 MVP。
- 部分字体和文章文件名有编码问题，不适合直接作为依赖。

## 对 InsightPulse 的设计启发

- 首页应从“后台面板”改成“信息博客/知识杂志”。
- 第一屏可以使用一张情绪背景图，并覆盖标题、日期和今日摘要。
- 文章应改成卡片流，每张卡片有频道、来源、标题、摘要和重要性。
- 侧边栏可以保留，但改成今日统计、热门关键词、信息源状态。
- 视觉可以走“清爽二次元科技博客”方向：天空蓝、薄荷绿、玻璃卡片、柔和阴影。
- 需要控制信息密度：优先展示今日精选，而不是所有抓取内容。
